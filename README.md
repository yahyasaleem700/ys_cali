# ys_cali website v2

GitHub Pages-ready static website for ys_cali.

## Files

- `index.html` — homepage
- `about.html` — athlete story and training philosophy
- `academy.html` — YS Calisthenics Academy
- `faq.html` — academy FAQ
- `style.css` — responsive visual system
- `script.js` — mobile navigation
- `images/logo.png` — main logo (you upload this)
- `images/favicon.png` — separate favicon (you upload this)
- `images/elbow lever park.jpg` — homepage hero photo (you upload this)
- `images/showcase/photo1.jpg`
- `images/showcase/photo2.jpg`
- `images/showcase/photo3.jpg`

## Important

The site does not include a Gallery page. The homepage has a small Instagram-focused showcase instead.

The navbar contains only real pages: Home, About, Academy, FAQ, Contact.

The Academy is intentionally pre-launch friendly; replace the interest-list section with your final registration form when ready.
